# 《大明国策》—— 明朝国策游戏

> 天子守国门，君王死社稷。

## 这是什么

一个**反爽游**的明朝历史策略游戏。22 个资源、5 个派系、75 个真实历史事件、6 级稳定度。你不是来当英雄的——你是来体会"为什么明朝一定会亡"。

**不做的事**：
- 不做"集齐18将打天下"
- 不做"穿越成皇帝拯救明朝"的爽文
- 不做"做对事就赢"的简单逻辑

**做的事**：
- 让你体会天启朝为何亡于魏阉+辽东
- 让你体会万历朝为何二十多年不上朝
- 让你体会"做对事也可能亡国"的系统绝望感

## 怎么玩

```bash
cd daming_guoce
python3 -m http.server 8000
# 浏览器开 http://localhost:8000/index.html
```

点右上角"下季"推进，每季80%概率会有急奏。每季结束有收入结算（农业、商业、税赋、季节性事件）。每年底做总结算。

## 核心系统

### 22个资源
按组分：经济（国库/内帑/粮/军粮/火药/铁/木/石/马）、民生（人口/稳定/威望）、军事（军力/水师）、天象（天命）、内政（行政/腐败/文化/科技/商业/农业/漕运）、外交（藩属）

### 5个派系
- **文官集团**（六部+内阁）
- **武将集团**（五军都督+九边）
- **宗室藩王**（各地藩王府）
- **宦官集团**（司礼监+禁府）
- **外戚集团**（后妃家族）

每个派系有自己的**下限**（过低触发"怠政/兵变/靖难/专权/干政"）和**上限**（过高触发"结党/拥兵/坐大/乱政/篡权"）。

### 6级稳定度
**鼎盛→稳定→正常→不稳→危机→崩溃**

每级影响：税收±、人口增长±、叛乱概率、士气。**稳定度是不可见的根本**，没有它，所有指标都崩。

### 75个事件（按类型）
- **灾害类 8个**：飞蝗蔽天、黄河决口、赤地千里、瘟疫横行...
- **边患类 7个**：鞑靼犯边、倭寇劫掠、土司叛乱、女真崛起...
- **内政类 20个**：举荐贤才、科场舞弊、宦官专权、党争爆发...
- **经济类 18个**：请开海禁、银矿之议、漕运淤塞、一条鞭法...
- **外交类 12个**：朝鲜来贡、日本遣使、安南叛服、红毛夷船...
- **皇族类 10个**：藩王请封、万贵妃干政、选秀之议...

### 5种结局
- **天命倾覆**：天命<20，民变蜂起
- **国库空竭**：财政破产，无以为继
- **军力崩解**：外虏深入，流寇四起
- **生灵涂炭**：人口锐减十不存三
- **二十载太平**：勉强续命，史家评"虽无大治"

## 与东汉版本的区别

- **资源从 8 → 22**：加入火药/铁矿/马匹/水师/内帑等明代特色
- **派系从 6 → 5**：去掉"流民/边将"独立派系，并入"武将集团"
- **节奏从"月-季-年" → "季-年"**：每季推进，20年上限
- **事件从 10 → 75**：完整明代事件库
- **加入稳定度6级**：不可见的根本指标
- **加入弹劾10种下场**：官员系统接口

## 设计哲学

**核心问题**：明朝为什么一定会亡？

不是皇帝不努力——是结构性矛盾。土地兼并 → 流民 → 边军欠饷 → 倭乱 → 辽东 → 三饷加派 → 农民破产 → 流寇 → 边将拥兵自重 → 中央失权。

**任何单一决策都没法破局**——这是游戏的"反爽游"设计哲学。玩家要体验的是**系统性的困境**，而不是"做对事就赢"。

## 技术栈

- 单页应用，零依赖
- 数据驱动：所有数值/事件/剧本都在 `data/script.js`
